# tahdeed demo data

The Abu Dhabi emirate region of the tahdeed gazetteer and a ranker trained on it, used by the hosted
demo on a free instance (512 MB). `gazetteer.sqlite.gz` unpacks to `gazetteer.sqlite`; `SHA256SUMS`
lists the hashes of the unpacked file, the archive and the ranker.

The data are derived from OpenStreetMap and available under the ODbL 1.0, see `NOTICE.md`. For the
full UAE data use `tahdeed fetch`, which reads the `data` branch.
