# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The full text applies to all project spaces, including issues, pull requests and discussions.

In short: be respectful, accept constructive criticism, focus on what is best for the project and its users, and do not harass anyone. Harassment, personal attacks and the publication of other people's private information are not accepted.

Maintainers may remove comments, close discussions or block contributors who breach these rules. To report a breach, use GitHub's private vulnerability reporting for this repository and mark the report as a conduct issue, or contact the maintainer through the profile linked from the repository. Reports are handled in confidence.
